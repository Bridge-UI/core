# i18n

Bridge chrome strings (aria-labels, empty/loading copy) resolve through an optional i18n adapter on `BridgeUIProvider` (`global.i18n`). Without an adapter, the English source string is returned as-is.

Lookup is **gettext-style**: the source English text is the key.

```ts
const resolveMessage = useResolveMessage();

resolveMessage("Hide password");
```

`useResolveMessage` reads the active adapter from context. **Interpolation and pluralization are the adapter’s job** (i18next, vue-i18n, or a custom `t`). Bridge `setLocale` updates `global.locale` and calls optional `adapter.setLocale` — persistence (localStorage, backend) stays in the app.

Implement `I18nAdapter` as a plain object — Bridge only defines the interface.

## Import

```ts
import { useResolveMessage, type I18nAdapter } from "@bridge-ui/react";
```

## Examples

### Resolve in a component

```tsx
function ClearButton() {
  const resolveMessage = useResolveMessage();

  return (
    <button type="button" aria-label={resolveMessage("Clear selection")}>
      Clear
    </button>
  );
}
```

### Dictionary adapter

Static source→string map (no replace/plural, no `setLocale`). Good for a fixed locale.

```ts
import { BridgeUIProvider } from "@bridge-ui/react";
import { createDictionaryI18nAdapter } from "@examples/i18n-dictionary";

const i18n = createDictionaryI18nAdapter();
```

```tsx
<BridgeUIProvider global={{ i18n }}>
  <App />
</BridgeUIProvider>
```

### Custom adapter

```ts
import type { I18nAdapter } from "@bridge-ui/react";

const messages: Record<string, string> = {
  Close: "Fechar",
  "Hide password": "Ocultar senha",
  "Clear selection": "Limpar seleção",
};

const i18n: I18nAdapter = {
  t(message) {
    return messages[message] ?? message;
  },
};
```

### i18next (replace & plural)

```ts
import i18next from "i18next";
import { createI18nextAdapter } from "@examples/i18n-i18next";

const i18n = createI18nextAdapter(i18next);

const resolveMessage = useResolveMessage();
resolveMessage("{{count}} item", { count: 3 });
// → i18next handles interpolation / plural rules

setLocale("pt-BR"); // Bridge locale + i18n.changeLanguage via adapter.setLocale
```

Other ready examples:

| File                 | Library              | Replace / plural |
| -------------------- | -------------------- | ---------------- |
| `i18n-dictionary.ts` | In-memory dictionary | No (static map)  |
| `i18n-i18next.ts`    | i18next              | Yes (via lib)    |
