# i18n

Bridge chrome strings (aria-labels, empty/loading copy) resolve through an optional i18n adapter on `BridgeUIProvider` (`global.i18n`). Without an adapter, the English source string is returned as-is.

Lookup is **gettext-style**: the source English text is the key.

```ts
resolveMessage("Hide password", i18n);
```

Bridge only calls `adapter.t(message, params?)`. **Interpolation and pluralization are the adapter’s job** (i18next, vue-i18n, or a custom `t`).

## Import

```ts
import { createI18nAdapter, resolveMessage } from "@bridge-ui/react";
```

## Examples

### Dictionary adapter

Simple source→string map (no replace/plural). Good for static chrome labels.

```ts
import { BridgeUIProvider } from "@bridge-ui/react";
import { createDictionaryI18nAdapter } from "@examples/adapters/react/i18n-dictionary";

const i18n = createDictionaryI18nAdapter("pt-BR");
```

```tsx
<BridgeUIProvider global={{ i18n, locale: "pt-BR" }}>
  <App />
</BridgeUIProvider>
```

### Custom map

```ts
import { createI18nAdapter } from "@bridge-ui/react";

const i18n = createI18nAdapter({
  Close: "Fechar",
  "Hide password": "Ocultar senha",
  "Clear selection": "Limpar seleção",
});
```

### i18next (replace & plural)

```ts
import { createI18nextAdapter } from "@examples/adapters/react/i18n-i18next";

const i18n = createI18nextAdapter(i18nextInstance);

// Later, when a component needs it:
resolveMessage("{{count}} item", i18n, { count: 3 });
// → i18next handles interpolation / plural rules
```

Other ready examples:

| File                 | Library              | Replace / plural |
| -------------------- | -------------------- | ---------------- |
| `i18n-dictionary.ts` | In-memory dictionary | No (static map)  |
| `i18n-i18next.ts`    | i18next              | Yes (via lib)    |
