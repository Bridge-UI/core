# i18n

Bridge chrome strings (aria-labels, empty/loading copy) resolve through an optional i18n adapter on `BridgeUIProvider` (`global.i18n`). Without an adapter, the English source string is returned, with `{{name}}` replaced from `params`.

Lookup is **gettext-style**: the source English text is the key. Multi-locale
adapters can keep the active locale internally via optional `setLocale`.

```ts
const resolveMessage = useResolveMessage();

resolveMessage("Hide password");
```

`useResolveMessage` reads the active adapter from context. **Pluralization is
the adapter’s job** (i18next, vue-i18n, or a custom `t`). Dictionary adapters
replace `{{name}}` from `params`; i18next already interpolates. Without an
adapter, `resolveMessage` still replaces `{{name}}` on the English source.
Bridge `setLocale` updates `global.locale` and calls optional `adapter.setLocale`
— persistence (localStorage, backend) stays in the app.

Implement `I18nAdapter` as a plain object — Bridge only defines the interface.

## Import

```ts
import { useResolveMessage, type I18nAdapter } from "@bridge-ui/react";
```

## Examples

### Resolve in a component

```tsx
function ClearButton() {
  const resolveMessage = useResolveMessage();

  return (
    <button type="button" aria-label={resolveMessage("Clear selection")}>
      Clear
    </button>
  );
}
```

### Dictionary adapter

Locale-keyed source→string map with `{{name}}` replace. Optional `setLocale`
updates the active locale used by `t`. For pluralization, wrap i18next.

```ts
import { BridgeUIProvider } from "@bridge-ui/react";
import { createDictionaryI18nAdapter } from "@examples/i18n-dictionary";

const i18n = createDictionaryI18nAdapter();
```

```tsx
<BridgeUIProvider global={{ i18n, locale: "pt-BR" }}>
  <App />
</BridgeUIProvider>
```

### Custom adapter

```ts
import { get } from "es-toolkit/compat";
import { interpolateMessage, type I18nAdapter } from "@bridge-ui/react";

const messages: Record<string, Record<string, string>> = {
  "pt-BR": {
    Close: "Fechar",
    "Hide password": "Ocultar senha",
    "Clear selection": "Limpar seleção",
  },
};

let locale = "en-US";

const i18n: I18nAdapter = {
  setLocale(next) {
    locale = next;
  },
  t(message, params) {
    return interpolateMessage(
      get(messages, [locale, message], message),
      params,
    );
  },
};
```

### i18next (replace & plural)

```ts
import { createI18nextAdapter } from "@examples/i18n-i18next";

const i18n = createI18nextAdapter();

const resolveMessage = useResolveMessage();
resolveMessage("{{count}} item", { count: 3 });
// → i18next handles interpolation / plural rules

setLocale("pt-BR"); // Bridge locale + i18n.changeLanguage via adapter.setLocale
```

| File                 | Library              | Replace / plural    |
